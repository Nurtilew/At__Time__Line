01 — GET STARTED

Жергілікті іске қосу.

Node.js 20+ талап етіледі. Жоба толық іске қосылуы үшін dependency-лер орнатылып, сервердің қоршаған орта параметрлері бапталуы қажет.

TERMINAL / SETUP

1. Пакеттерді орнату

Архивті ашып, жоба папкасында терминалға мына командаларды орындаңыз.

COMMANDS
npm install
npm run check
npm run hash-password

2. Қауіпсіз конфигурация

.env.example файлын .env деп көшіріңіз. Ұзын SESSION_SECRET, bcrypt әкімші пароль хэші және провайдерден алынған құпия кілттер қажет.

START SERVER
npm start
DEPLOY / CHECKLIST

Жариялау алдындағы тексеру

  1. Node.js-ты қолдайтын хост

    Тек static hosting API endpoint-терін орындамайды. Серверді іске қосатын хостинг таңдаңыз.

  2. Тұрақты HTTPS домені

    BASE_URL мәні сайттың жария HTTPS адресіне сәйкес болсын.

  3. Тұрақты дерекқор дискісі

    SQLite файлы қайта жариялағанда өшпейтін тұрақты сақтау орнына жазылсын.

  4. Алдымен test mode

    Провайдердің тест деректерімен толық айналымды тексерген соң ғана live режиміне ауысыңыз.

  5. Шынайы бизнес деректері

    Шарттар, құпиялық, қайтарым тәртібі және байланыс деректерін жариялау алдында толтырыңыз.

02 — API ROUTES

Қолжетімді endpoint-тер.

Маршруттардың нақты нәтижесі жария серверге, орта айнымалыларына және провайдер аккаунтына тәуелді.

Бұл жүйе лицензиясыз әмиян емес.

Freedom Pay төлем қабылдауға рұқсат беруі картаға ақша шығару рұқсатын автоматты түрде бермейді. Payout провайдердің жеке келісімімен, бөлек құпия кілтпен және live режимде ғана қосылады. Бұл код кез келген адамнан қаражат қабылдап, басқа клиентке автоматты түрде аударатын әмиянның орнына жүрмейді. Үшінші тарап ақшасын ұстап/аудару үшін провайдер талаптары мен Қазақстан заңнамасына сәйкестік жеке тексерілуі тиіс.
