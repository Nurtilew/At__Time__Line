PAYPORTAL KZ — ӘКІМШІ ҚҰПИЯСӨЗІН ӨЗІҢ ҚОЮ

ТҰРАҚТЫ NODE.JS ХОСТИНГІНДЕ:
1) npm install
2) .env.example файлын .env деп көшір.
3) npm start
4) /admin.html бетіне кір.
5) Алғашқы рет өз логинің мен 12–72 таңбалы (UTF-8 бойынша 72 байтқа дейін) құпиясөзіңді екі рет енгізіп, аккаунт жаса.
6) Қоғамға ашық production серверде бөтен адам бірінші болып тіркелмеуі үшін `.env` ішіне кемінде 32 кездейсоқ таңбалы `ADMIN_SETUP_TOKEN` орнатып, оны бір реттік формаға енгіз. Жергілікті компьютерде токен керек емес.
7) Кейін сол деректермен кір. Hash-ті қолмен жасау қажет емес.

NETLIFY ТУРАЛЫ МАҢЫЗДЫ:
Netlify Functions-та жергілікті SQLite және файлдар тұрақты сақталмайды. Сондықтан сайт ішіндегі setup формасы Netlify-де өшірілген. Netlify-де SESSION_SECRET пен ADMIN_PASSWORD_HASH Environment variables-та орнатылып, тұрақты дерекқор қосылуы керек. Бұл ZIP Netlify-де толық өндірістік төлем жүйесі деп расталмаған.

Құпиясөзді GitHub-қа немесе ашық ZIP-ке қоспа.
